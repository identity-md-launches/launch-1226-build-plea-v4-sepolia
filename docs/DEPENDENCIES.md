# Vendored dependencies and protocol provenance

- Uniswap `v4-core`, tag `v4.0.0`: `https://github.com/Uniswap/v4-core/tree/v4.0.0`. Source and upstream LICENSE are under `lib/v4-core/`. Production uses its interfaces, types and internal math; tests construct its actual PoolManager. Licenses are retained per file (including BUSL-1.1 for PoolManager).
- OpenZeppelin Contracts, tag `v5.4.0`: `https://github.com/OpenZeppelin/openzeppelin-contracts/tree/v5.4.0`. Contracts and MIT license under `lib/openzeppelin-contracts/`.
- Forge Standard Library, tag `v1.9.7`: `https://github.com/foundry-rs/forge-std/tree/v1.9.7`. Source and MIT/Apache licenses under `lib/forge-std/`.
- Solmate, tag `v6`, plus `src/auth/Owned.sol` at commit `89365b880c4f3c786bdd453d4b8e8fe410344a69`, needed by v4 core: `https://github.com/transmissions11/solmate`. Source and license under `lib/solmate/`.
- Oracle attestation types, hash, domain, decoders and the conformance vector were copied from the task's pinned oracle-consumer reference. The signer field is immutable and its internal setter is removed, as required by this task. OpenZeppelin 5.4's equivalent `SignatureChecker.isValidSignatureNow` takes a memory signature rather than the reference's newer calldata overload. The published viem digest/signature vector is tested unchanged.
- POOL4 source was retrieved through Sourcify v2: `https://sourcify.dev/server/v2/contract/1/0xc6c965bd164c483e87d0b550671798e9a3602840?fields=all`. Its original source is preserved as `POOL4-CappedBurnHook.sol.txt`, outside the compiler's source paths. The cap, ratchet clock/remainder, oriented placement floor, prior-block reference and measured keeper work were adapted. Owners' withdrawals, adjustable policy, native ETH, ERC-6909 deferred claims, rewards split and LP fees were removed for this task.
- Stacker source was retrieved through Sourcify v2: `https://sourcify.dev/server/v2/contract/11155111/0x293c7134ab8f6bf1d8ff44ed806575f8f1baf477?fields=all`. `test/fixtures/Stacker.sol` is the verified implementation. Its `Stacked` event records the caller as project.
- The Intake `requests(bytes32)` ABI was verified against `https://sourcify.dev/server/v2/contract/1/0x1397434cd35e8a9c8ac312a61d3a285eb31dea56?fields=all`: `(address payer,address callbackTarget,bytes4 callbackSelector,bool completed)`. Intake marks completed before attempting its 200,000-gas callback, so the callback checks its own pending state and deadline; the separate clearing path reads completed.

No submodules, package installation at build time, compiler binaries, or external library links are required. Solidity library functions called by the application are internal/inlined.
